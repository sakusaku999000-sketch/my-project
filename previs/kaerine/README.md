# 『返り音（かえりね）』プリビズ

脚本 v1.0（全9シーン・約6分30秒・72ショット）を、Blender のグレーマネキンと簡易セットで動画化したプリビズ一式。

## 成果物

| ファイル | 内容 |
|---|---|
| `video/kaerine_previs_full.mp4` | 全編（字幕・ショット情報・仮の効果音付き） |
| `video/sc1.mp4` 〜 `sc9.mp4` | シーン別 |
| `storyboard/STORYBOARD.md` | 絵コンテ（各ショットの中間フレーム＋サイズ・カメラワーク・内容・セリフ・SE） |
| `storyboard/SC1_storyboard.png` 〜 | シーン別の絵コンテ画像 |

画面の見方：上の黒帯にシーン・ショット番号・サイズ/レンズ・カメラワークと全体タイムコード、下の黒帯にセリフ字幕。
効果音（トン、トン／鐘／崩落など）はタイミング確認用の仮音です。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `lib.py` | 共通部品（ショット表、マネキン、カラス、カメラ、波紋、蝶、水面の映り込み） |
| `sets.py` | セット（蓮の部屋、夜/朝の神社、彼岸の水鏡世界、飛び石） |
| `sc1.py` 〜 `sc9.py` | 各シーンのショット表（`SHOTS`）と演出（カメラ・人物の動き） |
| `build.py` | シーンを組み立て、レンダーする入口 |
| `compose.py` | 連番に黒帯・字幕・ショット情報・効果音を重ねて mp4 にする |
| `storyboard.py` | 絵コンテ画像と STORYBOARD.md を作る |

ショットの尺・セリフ・説明は各 `scN.py` 先頭の `SHOTS` を書き換えるだけで、動画と絵コンテの両方に反映されます。

## 使い方

Blender（5.1 で確認）で確認するだけなら：Scripting タブで `build.py` を開き、`SCENE = 1` を書き換えて実行。タイムラインのマーカーでショットごとにカメラが切り替わります。

書き出し（コマンドライン）：

```
blender -b -P build.py -- --scene 1 --stills out/sc1/stills --render out/sc1/frames --res 854
python3 storyboard.py out storyboard
python3 compose.py out video
```

`--render` は 2 フレームおき（12fps）で書き出します。

## 脚本からの主な演出判断

- SC4 の鳥居は、進むほど朱→白→青に褪せ、通路がねじれ、石畳が水面に変わる。最後の鳥居が崩れて光の門が開く。
- 彼岸（SC5〜8）は水面を描かず、上下反転した複製で「水鏡」を表現（映り込みは水色寄りに暗く）。
- SC6-2 は脚本どおり水面の映り込みだけで二人を見せる。
- 「トン、トン」は SC1・2・3・5・8・9 のすべてで画と効果音のタイミングを合わせている。
- 尺は脚本の各シーンの時間配分（合計 6:30）に合わせた。
